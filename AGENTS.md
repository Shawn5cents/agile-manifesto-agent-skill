# Agent compatibility

This repository contains an Agent Skill whose canonical instructions are in `SKILL.md`.

When an agent supports the open Agent Skills format, install or link this repository as a skill and let the agent discover it from the `name` and `description` metadata.

When an agent does not support skill discovery, read `SKILL.md` when the task involves software planning, implementation, debugging/rescue, product prioritization, team process, retrospectives, or reviewing a workflow against Agile principles. Follow `SKILL.md` as the source of truth.
