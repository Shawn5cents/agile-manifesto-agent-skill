# Gemini compatibility

This repository is an Agent Skill. `SKILL.md` is the canonical instruction file.

Gemini CLI can install a Git-hosted Agent Skill directly. If installed manually, place or link this skill under a supported skills directory such as `.gemini/skills/agile-manifesto/` or `.agents/skills/agile-manifesto/`. Keep `SKILL.md` as the single source of truth.
